# Reports Directory

`reports/` contains audits, reviews, analyses, and dated working notes.

## Status

- Reference only
- Date-sensitive
- Not canonical governance

## Use Rules

- Do not treat files in `reports/` as authority over `AGENTS.md`, `governance/`, active tasks, or committed runtime files.
- Reports may contain stale assumptions about routes, CSS entry points, or repository structure.
- If a report is still useful, cite its date and re-verify against the current repository before using it.

## When Conflicts Happen

If a report conflicts with current runtime files or governance docs:

1. follow `AGENTS.md`
2. follow `governance/`
3. follow committed route files and `styles.css`
4. treat the report as historical context only
